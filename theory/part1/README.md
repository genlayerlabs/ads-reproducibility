# Part 1 numerical reproduction

This directory is the standalone numerical companion to *Aggregate
Disambiguation Systems*. The Nix flake pins the Python, NumPy, SciPy,
Matplotlib, font, and renderer environment used for the archived paper
figures. All commands are deterministic except for the Monte Carlo study,
whose fixed seeds and scenario-specific seeds are recorded in the published
summary CSV.

## Verification

From the repository root:

```bash
nix-shell --run 'make test-theory'
```

The suite checks exact binomial calculations, Clopper--Pearson coverage,
certificate monotonicity and soundness, the frozen panel schedule, and the
non-adaptive corruption formulas.

## Paper artifacts

```bash
nix-shell --run 'make theory-figures'
```

This regenerates Figures 1--3 and 5--8. Figure 4 and its two CSV tables are
regenerated by the full published Monte Carlo study:

```bash
nix-shell --run 'make theory-monte-carlo'
```

That command runs the four predeclared scenarios with 2,000 repetitions each
and base seed 5510. The output is written to `results/` and `figures/`.
Figure 9 comes from the sanitized empirical release under `results/paper/`.

The files in `results/` are generated artifacts and must not be edited by
hand. Their statistical scope and generation parameters are documented in
[`results/README.md`](results/README.md).

For non-Nix environments, `requirements.txt` records the direct numerical
package versions. Exact PNG reproduction additionally depends on the renderer
and fonts fixed by `flake.lock`; the CSV results do not.
